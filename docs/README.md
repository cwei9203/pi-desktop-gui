# Pi GUI

一个面向日常编程的 Pi 桌面客户端。使用 MyGo 承载桌面窗口，通过 Pi 官方 RPC 复用模型、工具和会话能力。

**当前状态：M0/M1 的第一段实现，已能构建 macOS 桌面应用。** 已接入本机 Pi RPC，提供项目连接、会话列表、对话界面和运行干预。完整首期功能仍在开发，不能将当前实现视为全部 P0 已完成。

## 启动

先准备 Go 1.27.1、Bun 1.4.3 和已完成模型认证的 Pi 1.4.0，在项目根目录执行：

```sh
go mod download
bun install --frozen-lockfile
bun run dev
```

桌面窗口中选择项目，系统目录选择器返回后直接连接；最近项目可一键连接，无需再次确认 Pi 路径。应用自动查找 Pi；缺失、版本不符或无法运行时，在页面内展示安装与重试入口。手动路径和项目资源批准放在用户主动打开的「设置 → 高级设置」中；项目资源批准默认关闭，只用于本次指定项目的连接，不跨项目继承。`bun run dev:web` 仅预览界面，普通浏览器不能连接本机 Pi。

构建本地应用：

```sh
bun run build
open "build/darwin-arm64/Pi GUI.app"
```

构建环境与完整步骤见 [开发与运行指南](development.md)。

## 当前实现

- **桌面与连接**：MyGo WebView、选择目录后直接连接、最近项目一键连接、Pi 自动发现与版本检查、页面内安装引导、单实例与单活跃 Pi 进程。
- **会话与模型**：GUI 管理的会话索引、新建与恢复、模型切换；未自动导入已有 Pi TUI 历史。
- **对话与执行**：流式 Markdown、工具卡片、追加指令、后续消息排队、停止并取回队列文字。
- **交互与恢复**：暖灰窄侧栏、统一标题栏、圆角输入区、页面内设置；基础扩展弹窗、通知、草稿、明暗主题、事件序号与快照同步、退出清理。

自动发现覆盖已保存路径、PATH、standalone、npm/Bun 和常见 Node 管理器目录；返回 `ready`、`missing`、`unsupported` 或 `unavailable`，探测有超时和输出上限，不读取 shell 配置。安装引导固定到官方 Pi v1.4.0 Release，提供可复制的版本固定 npm 命令和 Node 要求，详见 [开发指南](development.md)。界面借鉴 Claude Desktop 的信息层次，不声称一比一复刻，来源见 [产品方案](product-plan.md)。

本次连接与界面调整前已有证据：macOS Apple Silicon 构建成功，生成约 9.4 MB 的 `.app` 和约 2.8 MB 的 DMG；本机 Pi 1.4.0 的 RPC 握手返回 49 个可用模型。桌面应用已使用 Deepseek-V4.1-Flash 完成一次真实只读任务，通过 `read` 工具读取隔离临时项目的 `sample.txt`，正确展示两行中英文内容；文件内容断言保持不变，会话工具记录仅有 `read`。

Go 竞争检查、静态检查、前端状态测试和前端构建均已通过。正常 `Cmd+Q` 退出后无该 GUI 或其 Pi RPC 进程残留；重新启动并连接同一项目后，用户消息、`read` 结果和完整回复均恢复，没有自动发送任务。空闲时关闭窗口并创建新窗口，连接、历史和未发送的中文草稿也保持完整。

本轮连接与界面调整后，`go test -race ./...`、`go vet ./...`、`bun test src`（11 项、56 个断言）和 `bun run build` 均通过；构建仍生成约 9.4 MB `.app` 与约 2.8 MB DMG。真实 `DetectPi` 加空路径 `Start` 握手通过，识别 Pi 1.4.0 并返回 49 个模型。原生桌面已确认无需填写 Pi 路径，系统选目录后直接连接并恢复历史，没有二次配置弹窗；最近项目点击直接开始连接。首页和设置截图中，暖灰侧栏、统一标题栏无遮挡；设置位于主区域，高级选项默认折叠。

本轮未安装或卸载 Pi；`missing`、`unsupported`、`unavailable` 由隔离 fixture 与组件渲染测试覆盖。没有发起新的模型 prompt，未手动验证深色主题或中文 IME。运行中重开窗口、真实任务的停止与恢复、长对话仍需继续验收；上述记录不是性能或完整 P0 通过结论。

## 原定首期目标

- **平台**：先做 macOS 自用版，优先 Apple Silicon；其他平台另行验证。
- **技术**：MyGo + React + TypeScript + Pi RPC；使用 WebView 构建界面。
- **布局**：左侧项目与会话，中间对话与输入，右侧可收起的修改查看区。
- **运行**：复用本机已安装、已配置认证的 Pi；首期只运行一个活跃会话。
- **重点**：会话恢复、流式消息、工具执行展示、运行中干预、可靠停止、只读 Git diff。

上述内容是原定首期范围；右侧 Git diff、图片输入、推理级别、命令入口等尚未完成。第一版先跑通真实 Pi 的完整使用流程，再逐项完成 [产品方案](product-plan.md) 中的验收标准。

## 范围边界

首期不内置模型服务，不重写 Pi Agent，不做完整 IDE、多 Agent 调度、远程执行或云同步。不自动导入已有终端会话，不承诺兼容依赖终端组件的全部 Pi 扩展。

GUI 不提供额外沙箱；Pi 仍使用当前操作系统用户的权限。后续修改区将显示整个工作区当前变更，不能把所有变更归因于 Pi。
